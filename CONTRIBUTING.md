# Contributing to this proposal

This repository is the home of the **Design by Contract** proposal for ECMAScript (currently Stage 0). Discussion happens here — via issues — not in private channels and not on unrelated trackers.

## How to participate

1. **Open an issue** for anything: critique of the semantics, prior-art corrections, questions about the reference implementation, venue suggestions (community feedback calls, meetups, mailing lists).
2. **Critique the failure semantics and performance claims first** — those are the two load-bearing sections of the proposal. Links and counterexamples are welcome.
3. Be concrete: "section X, paragraph Y, here is a broken case" beats "I don't like this". A failing example written against the reference implementation is the gold standard — minimal repro, expected vs actual.
4. Avoid bikeshedding names without a reason. Renaming `pre`/`post` needs an argument, not a preference.

## Ground rules

- Be respectful and specific. This is a public technical discussion; hostile-but-correct beats polite-but-empty.
- No commercial promotion. This proposal is not a vehicle for a product.
- If you are a TC39 member willing to champion, or know one, say so in an issue — that is the single most useful thing you can do right now.
